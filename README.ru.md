**Одна страница, на которой видно, что вашим ИИ-агентам нужно от вас, и самое дорогое ожидание стоит первым.**

Для тех, у кого одновременно работает много агентов (сессии Claude Code, Codex, задачи по расписанию) и два вопроса, без
ответа на которые всё стоит, теряются где-то в десятке окон.

![Главный экран: что ждёт вас, по важности, и что сейчас в работе](docs/screenshots/now-desktop.png)

**[Открыть живое демо](https://dmitrykarpushkin.github.io/needsyou/)**: данные выдуманные, ставить ничего не нужно.

## Зачем

- **Список дел, а не стена плиток.** Каждая строка — обычное предложение: что сделать и где, например «смержить PR #214
  в api-service: проверки зелёные, ревью есть». Никаких счётчиков, которые надо расшифровывать.
- **Сначала то, что дороже всего ждёт.** Работа, которая стоит до вашего ответа, потом дешёвые мержи, которые разблокируют
  остальных, потом обычные просьбы. Зависшие сессии и старые неважные просьбы уходят из списка сами, так что он не только растёт.
- **Все агенты на одной странице.** Пулл-реквесты, сессии, которые ждут ответа, задачи по расписанию, запуски служб, бэклог и
  очередь идей — из всех проектов сразу, а не по окну на каждый инструмент.
- **Ничего не выдумывает.** Показывает только то, что записали машины: состояние PR из GitHub, журнал запусков, сигналы «я жив».
  Если поля нет, так и написано, что неизвестно; данные старше 15 минут помечаются, а service worker ничего не кэширует.
- **Подойдёт любой бэкенд, который умеет писать JSON-файлы.** Страница только читает файлы, хватит крона и статической папки.
  Формат описан поле за полем.
- **Удобно с телефона.** Ставится как PWA, есть мобильная раскладка и нижняя панель.

## Чем отличается от других

Инструменты ниже больше и взрослее; needsyou делает одну узкую вещь, которой у них нет. Их можно использовать вместе.

| Инструмент | В чём он силён | Чем needsyou отличается |
|---|---|---|
| Claude Code agent view (`claude agents`, превью) | Родной список сессий Claude Code, отвечать можно прямо там | Один список по разным инструментам и источникам (PR, таймеры, службы, бэклог); только чтение |
| [Conductor](https://www.conductor.build), [Vibe Kanban](https://github.com/BloopAI/vibe-kanban), [claude-squad](https://github.com/smtg-ai/claude-squad) | Запускают и изолируют агентов, показывают их диффы | Агентов не запускает; читает, что произошло где угодно, и ранжирует то, что нужно от человека |
| [Langfuse](https://github.com/langfuse/langfuse), [Helicone](https://github.com/Helicone/helicone) | Трейсы, стоимость, задержки, оценки по каждому вызову модели | Ваше следующее действие («смержить PR #214»), а не трейсы |
| [Uptime Kuma](https://github.com/louislam/uptime-kuma), [Homepage](https://github.com/gethomepage/homepage) | Проверки доступности, оповещения, статус-страницы, много интеграций | Запуски агентов на шкале расписания, связанные с тем же списком; сам ничего не проверяет и не оповещает |

Берите другие, если нужно действовать прямо со страницы, запускать агентов или получать оповещения: needsyou только читает, своего
входа по паролю у него нет, а сборщики данных, которые его кормят, в этот репозиторий не входят.

## Быстрый старт

```sh
git clone https://github.com/dmitrykarpushkin/needsyou && cd needsyou
npm install
npm run dev        # http://localhost:5173 с демо-данными
```

Чтобы показать свои данные, соберите с `VITE_DATA_SOURCE=http VITE_DATA_URL=<где лежат ваши JSON-файлы>` и положите `dist/` на
любой статический хостинг. Что должно быть в каждом файле — в [docs/DATA.md](docs/DATA.md) (на английском).

## Как это устроено

```
ваши сборщики (cron, CI, хуки)  ->  JSON-файлы  ->  needsyou их опрашивает  ->  rank.ts строит «Needs you»  ->  страницы
```

Страница перечитывает фиксированный набор файлов (`asks.json`, `prs.json`, `agents.json`, `schedules.json`, журнал запусков и ещё
несколько) раз в 20 секунд — 5 минут или слушает необязательный поток Server-Sent Events. Все правила ранжирования — чистые функции с
юнит-тестами. Страницы: Now, Projects, Agents, Schedule, Activity, Wiring (инструкции, скиллы и хуки, с которыми работают агенты),
Backlog, Lab.

## Состояние

Личный проект, версия 0.1.0. React 19, TypeScript, Vite, Tailwind; 13 юнит-тестов на ранжирование, расписания и демо-данные,
UI-тестов нет. В исходной установке страница живёт на личном сервере за логином и получает данные от закрытых сборщиков; здесь она
идёт с выдуманными демо-данными. Не измерено, сколько времени она экономит и совпадает ли её порядок с тем, что срочно для другого
человека. Изменения — в [CHANGELOG.md](CHANGELOG.md).

## Откуда это

Выделено 26 октября 2026 года из закрытого репозитория, где я строю обвязку для работы ИИ-агентов под независимыми проверками. Там
у этой страницы 85 коммитов с 19 по 22 октября 2026 года, 84 из них сделали агенты, работавшие под этими проверками (цифры из
закрытой истории; она не публикуется, потому что в ней есть рабочие проекты и внутренние идентификаторы). Этапы с датами —
в [CHANGELOG.md](CHANGELOG.md).

Один из трёх репозиториев:

- [stopline](https://github.com/dmitrykarpushkin/stopline): git-хуки и хук для Claude Code, которые не пропускают то, что агент
  заявил, но не сделал.
- [foureyes](https://github.com/dmitrykarpushkin/foureyes): агент, который сделал изменение, никогда сам его не проверяет и не
  принимает. Его доску идей можно отдать этой странице как `lab.json` без переделок.
- needsyou (этот репозиторий): страница, на которой результаты обоих доходят до человека.
